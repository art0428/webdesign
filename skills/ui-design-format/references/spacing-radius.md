## 五、間距、圓角與框線

### 5.1 間距標尺（4px 基準）

所有 margin 與 padding 一律取自此標尺，不得出現標尺以外的數值（例如 13px、18px）。

| Token | 值 | rem | 典型用途 |
|-------|-----|-----|----------|
| `--sp-1` | 4px | 0.4rem | 圖示與文字之間、說明文字到輸入框 |
| `--sp-2` | 8px | 0.8rem | 元件內的小間隔、並排的小按鈕、**欄位標籤到輸入框** |
| `--sp-3` | 12px | 1.2rem | 元件之間的標準間距、表格儲存格垂直內距、欄位之間、欄格的緊湊欄距（6.5） |
| `--sp-4` | 16px | 1.6rem | 卡片垂直內距、區塊內元素間距 |
| `--sp-5` | 20px | 2.0rem | 卡片、儲存格、表頭、表格標題列的水平內距 |
| `--sp-6` | 24px | 2.4rem | 區塊與區塊之間、欄組之間、欄格的標準欄距與桌機容器內距（6.2、6.5） |
| `--sp-7` | 32px | 3.2rem | 大區段之間 |
| `--sp-8` | 40px | 4.0rem | 頁面區段分隔 |
| `--sp-9` | 48px | 4.8rem | 頁首與內容之間 |
| `--sp-10` | 64px | 6.4rem | 頁面上下留白 |

**命名以 CSS 為準**：token 連號 `--sp-1`〜`--sp-10`，不是「4px 的倍數」。v17 以前本表寫 space-8＝32px、space-12＝48px，而 `tokens.css` 與七套元件庫一直是 `--sp-7`＝32px、`--sp-9`＝48px，工程師照舊表找 `--sp-8` 會拿到 40px。v18 起兩邊一致。

全站最常出現的兩個內距，一律取自標尺：

| 位置 | 垂直 | 水平 |
|------|------|------|
| 卡片內距 | 16px（1.6rem） | 20px（2.0rem） |
| 表格儲存格 | 12px（1.2rem） | 20px（2.0rem） |

儲存格比卡片緊，是刻意的——表格要密、卡片要鬆。兩者水平內距相同，卡片與表格並排時左緣才會對齊。表頭 `th` 與表格標題列 `.tcap` 的水平內距同樣是 20px，表頭、標題列、儲存格、卡片四者左緣才會對齊；v17 以前 S1、S4、S6、S7 用 16px，基準 S1 本身就錯了。批次選取的勾選欄 `.ck` 是 36px 窄欄，右內距 0，為唯一例外。**表格列的高度由這個內距與列內容決定，不另設 `min-height`**（見 5.4）：純文字列 12 ＋ 12 ＋ B2 行框 21.25 ＋ 1px 線 ≈ 46px，含狀態膠囊的列約 50px。

### 5.2 圓角尺度（四級，固定）

| 級別 | 值 | 用在哪 |
|------|-----|--------|
| 焦點框 | 18px | 頁面的招牌元件（重點標註框）、確認彈窗 |
| 大容器 | 16px | 表格外框、標題卡片、大面板 |
| 小件 | 12px | 統計卡、輸入框、選項 chip、下拉面板 |
| 膠囊 | 999px | **所有按鈕**、狀態標籤、篩選器、搜尋框、數量調整器、側欄選中項 |

設計邏輯：**面積越大，圓角越大**（大面積配小圓角會顯得生硬，小面積配大圓角會變玩具感）。

**按鈕圓度一律一致**：全部膠囊，不因重要性改變形狀。按鈕的層級只靠「填色」區分——實心 accent-1 ＝主要動作、accent-1 外框＝強調動作、灰框＝一般動作、error 紅框＝不可回復動作。

**風格層例外（僅 S6 石墨）**：按鈕與輸入框改為 **6px**、卡片與表格容器改為 **12px**；狀態膠囊、篩選膠囊、屬性 tag 仍維持 999px。這與 S4 手帳的手繪歪框、S5 極光的一角收尖同性質——都是風格的表面覆寫，不是破例。

**風格層例外（僅 S7 編輯）**：卡片、表格容器、面板、彈窗、選單一律 **0**（直角）；按鈕、輸入框、選項 chip、篩選、狀態標籤、屬性 tag **2px**；頭像與圓點維持正圓。實作上把 `--r-lg` 設為 0、`--r-sm` 設為 2px。雜誌的版面是直角的，圓角會把它拉回 App 的語彙。

其餘四套依上表。

### 5.3 框線與陰影

- 框線一律 **1px**，色 `--line`。
- 選中或聚焦狀態的框線 **1.5px**，色 `--acc`。
- **預設零陰影**。層次靠框線、底色深淺（`--band` 與 `--card`）與留白建立，不用 box-shadow。
- 例外：S2 浮雕（雙向柔影）、S3 琉璃（面板投影）、S4 手帳（硬影位移）三套風格的視覺原理就建立在陰影上，依第八章各自的定義實作。S1 奶油、S5 極光、S6 石墨與 S7 編輯維持零陰影。

### 5.4 元件標準尺寸（結構層，七套共用）

元件的高度是**結構**，不是材質：風格層只准改顏色、框線、陰影、圓角，**不准出現 `min-height` 與 `padding`**。v16 以前這張表只是數字，沒有落到 CSS，結果七套元件庫的同一顆按鈕量出三到四種高度（S1 39px、S2 45px、S4 41px）。v17 起高度做成 token，寫法固定如下：

```css
:root{--h-btn-primary:4.0rem;--h-btn:3.8rem;--h-btn-sm:3.2rem;--h-input:4.0rem;--h-qty:3.4rem;--h-pill:2.4rem;--h-nav:3.8rem;--h-tag:2.0rem}
@media (max-width:767px){:root{--h-btn-primary:4.4rem;--h-btn:4.4rem;--h-btn-sm:4.0rem;--h-input:4.4rem;--h-qty:4.4rem}}
.btn{min-height:var(--h-btn);padding:0 var(--sp-5);display:inline-flex;align-items:center;justify-content:center}
```

三條規則：

一、**高度用 `min-height` 鎖定，不用 `height`**（理由見 4.7）。多行內容可以更高，但不得更低。
二、**垂直內距歸零，用 flex 置中。** 高度不再是「內距 ＋ 行框 ＋ 框線」算出來的，所以 S4 手帳的 2px 框線、S2 浮雕的無框線都被 `box-sizing:border-box` 吸收，七套算出來一模一樣。
三、**水平內距只取標尺**，列在下表。風格層不得改。

| 元件 | 桌機 | 行動裝置 | 水平內距 | 說明 |
|------|------|----------|----------|------|
| 主按鈕 `.btn.primary` | 4.0rem | 4.4rem | `--sp-6` 24px | |
| 一般按鈕 `.btn`、危險鈕 `.btn.danger` | 3.8rem | 4.4rem | `--sp-5` 20px | |
| 小按鈕 `.btn.sm` | 3.2rem | 4.0rem | `--sp-3` 12px | 警示條內的文字動作豁免（7.3） |
| 輸入框、下拉選單 | 4.0rem | 4.4rem | `--sp-3` 12px | 字 16px 防 iOS 放大；多行輸入不鎖高 |
| 搜尋框 | 4.0rem | 4.4rem | 膠囊 | |
| 數量調整器 `.qty` | 3.4rem | 4.4rem | 加減鈕各 3.2rem 寬 | 加減鈕與輸入格 `min-height:3.0rem`，容器框線另計（v20：框線 1px 或 2px 都由 3.4rem 決定高度） |
| 狀態膠囊 `.st` | 2.4rem | 2.4rem | `--sp-3` 12px | 不是可點元件，不放大 |
| 篩選膠囊 `.pillf` | 3.2rem | 4.0rem | `--sp-4` 16px | 同小按鈕 |
| 選項 chip `.chip` | 3.8rem | 4.4rem | `--sp-4` 16px | 同一般按鈕 |
| 屬性 tag `.tag` | 2.0rem | 2.0rem | `--sp-2` 8px | 承載 L2 11px |
| 側欄項目 `.nitem` | 3.8rem | — | `--sp-4` 16px | 手機收進抽屜選單 |
| 表格列 | 由內容決定 | — | 儲存格 `--sp-3` / `--sp-5` | 不另設高度：純文字列 ≈46px、含狀態膠囊約 50px |

**行動裝置的 4.4rem（44px）是觸控目標的國際慣例下限**，小於這個尺寸手指容易點錯。狀態膠囊與屬性 tag 不是可點擊元件，所以不受此限。

**表格列為什麼不鎖高度**：舊版寫 4.4rem，但儲存格內距 12px 與 B2 行框 21.25px 加起來就是 45.25px，再加 1px 線是 46px——用標尺上的任何內距都湊不出 44。與其寫一個做不到的數字，不如規定派生方式：列高 ＝ 上下內距 `--sp-3` ＋ 列內最高的內容。純文字列 46px；放了 24px 狀態膠囊的列，膠囊置中於行框，約 50px。要更密的表格，調的是儲存格內距（`--sp-2`），不是列高。

**驗收：交付前跑 `audit_sizes.py`，這是第五項自動檢查。** 它把頁面渲染出來，對上表每個元件取所有實例的實際高度：一、與規範值相差不得超過 1px（多行內容與被 flex 拉伸者可以更高，不得更低）；二、`min-height` 的計算值不得是 `auto` 或 `0px`；三、七套（加 S6 深色）同一元件的眾數必須相同（相差 1px 內視為相同）；表格列改量儲存格上下內距是否等於 12px；四（v21）、**框線貼合與分隔線重複**：兩個四邊都有框線的元件（小於 20px 的圖示、勾選框、色點不量）邊緣距離低於 8px，或兩條分隔線相距 12px 以內、64px 以內而中間沒有內容，或分隔線貼在容器級框的上下緣 12px 以內，皆不通過（9.3 第六、七條；刻意相連的組件與浮層豁免，清單見腳本）。任何一條不是 0 即不通過。元件庫現況（v21 四條）：八份（含 S6 深色）與八張前台示範頁皆 0 不合規；v16 同一支腳本量出 740 處 `min-height` 未鎖定、11 個元件七套不一致。

### 5.5 動態（時長與緩動）

動態的時長與緩動和字級、間距一樣是 token，**不得寫死秒數**。

| Token | 值 | 用在哪 |
|---|---|---|
| `--dur-1` | 120ms | 顏色、框線、陰影的狀態變化：滑過、聚焦、按下、表格列反白 |
| `--dur-2` | 200ms | 元件內的位移與展開：開關滑塊、折疊箭頭、下拉選單、提示氣泡 |
| `--dur-3` | 320ms | 大面板的進出：彈窗、側滑面板、Toast 淡出 |
| `--ease-out` | `cubic-bezier(.2,0,0,1)` | 進場與狀態變化——快起慢停，東西「落定」 |
| `--ease-in` | `cubic-bezier(.4,0,1,1)` | 退場——慢起快走，東西「離開」 |

```css
:root{--dur-1:120ms;--dur-2:200ms;--dur-3:320ms;
      --ease-out:cubic-bezier(.2,0,0,1);--ease-in:cubic-bezier(.4,0,1,1)}
@media (prefers-reduced-motion:reduce){:root{--dur-1:0ms;--dur-2:0ms;--dur-3:0ms}}
.btn{transition:background var(--dur-1) var(--ease-out)}
```

- **可以做轉場的屬性**：顏色、背景、框線色、陰影、`opacity`、`transform`。**不可以**：`width`、`height`、`top`、`left`、`margin`、`padding`——這些會觸發重新排版（瀏覽器重算整頁版面），動起來會卡。要移動東西用 `transform:translate()`。
- **不寫 `transition:all`**。列出實際會變的屬性，否則日後加一條樣式就會意外跟著動。
- **退場比進場短一級**：彈窗以 `--dur-3` 進場、`--dur-2` 退場。使用者關掉東西時不想等。
- **元件內的動畫不超過 `--dur-3`**。超過 320ms 的動畫在後台會讓人覺得系統慢。
- **迴圈動畫不受此表限制**：骨架屏的流光、處理中的轉圈，週期依元件自己的設定。
- **減少動態**：使用者在系統設定開啟「減少動態」時，三個時長自動歸零（見上方 CSS），元件不必逐條覆寫。迴圈動畫另依 10.5 處理。

### 5.6 層級（z-index）

疊在頁面上的東西只有五層，值做成 token，**不得出現表外的 `z-index`**。沒有層級表的後果是每個工程師自己挑數字（v17 以前的元件庫裡散落著 1、5、6、50、60），最後一定有人寫 9999。

```css
:root{--z-sticky:10;--z-pop:20;--z-drawer:30;--z-modal:40;--z-toast:50}
```

| 層 | token | 值 | 用在 |
|---|---|---|---|
| 吸附 | `--z-sticky` | 10 | 吸附表頭、頂列、手機底部固定條 |
| 浮層 | `--z-pop` | 20 | 下拉選單、就地確認、自動完成、日期選擇器 |
| 面板 | `--z-drawer` | 30 | 側滑面板與它的遮罩 |
| 彈窗 | `--z-modal` | 40 | 彈窗與它的遮罩 |
| 通知 | `--z-toast` | 50 | Toast、提示氣泡 |

同一層內靠 DOM 順序決定前後，不另外加數字。元件內部的局部堆疊（例如步驟精靈的圓點壓在連接線上）用 `z-index:1` 並在元件根建立 `isolation:isolate`，不會逃出元件影響這張表。
