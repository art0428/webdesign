## 六、RWD 響應式規範

### 6.1 斷點定義

```css
/* 手機直立 */            @media (max-width: 479px)
/* 大手機／手機橫向 */     @media (min-width: 480px) and (max-width: 767px)
/* 平板 */                @media (min-width: 768px) and (max-width: 1023px)
/* 筆電 */                @media (min-width: 1024px) and (max-width: 1279px)
/* 桌機 */                @media (min-width: 1280px)
```

實務上只有兩個斷點真正改變版型，其餘只是微調：

- **768px**：主要分界。側欄收合、多欄變單欄、表格轉卡片。
- **480px**：次要分界。網格清單從兩欄變一欄（商品卡列表例外，維持兩欄，見 6.3）、按鈕改為滿版寬度。

五個級別的名稱（v22）。名稱給第六、九章與日後的版型條文引用；CSS 的 media query 照舊寫像素：

| 級別 | 範圍 | 原名 | 欄格（6.5） |
|------|------|------|------|
| 緊湊 | < 480px | 手機直立 | 4 欄 |
| 中 | 480〜767px | 大手機／手機橫向 | 8 欄 |
| 平板 | 768〜1023px | 平板 | 8 欄 |
| 寬 | 1024〜1279px | 筆電 | 12 欄 |
| 特寬 | ≥ 1280px | 桌機 | 12 欄 |

對標：Material 3 的視窗級別是 600／840／1200／1600，IBM Carbon 是 672／1056／1312／1584；本規範沿用既有的 480／768／1024／1280，只補級別名稱與欄數。

### 6.2 容器寬度

| 情境 | 最大寬度 | 左右內距（即欄格外邊距，6.5） |
|------|----------|----------|
| 後台內容區 | 1060px | 寬與特寬 `--sp-6` 24px／平板 `--sp-5` 20px／中與緊湊 `--sp-4` 16px |
| 前台頁面 | 1080px | 同上 |
| 表單型頁面（結帳、設定）與**長文閱讀** | 720px | 同上 |

v22 以前桌機寫 26px，26 不在 5.1 標尺上；元件庫與 `dist/` 本來就用 24px，改的是條文。720px 容器加「長文閱讀」用途：一行約 40 個中文字，落在 W3C 中文排版需求（clreq）建議的範圍內。

超過最大寬度時內容置中，兩側留白。不做滿版拉伸——表格列太長會讓眼睛從左掃到右時掉行。

### 6.3 各類畫面的響應行為

**導覽框架**

| 斷點 | 行為 |
|------|------|
| ≥ 1024px | 左側欄固定展開 226px，內容區自適應 |
| 768〜1023px | 側欄縮成 64px 只留圖示，滑鼠移上去展開浮層 |
| < 768px | 側欄完全隱藏，改為左上角漢堡選單開啟的抽屜（覆蓋式，右側半透明遮罩） |

**資料表格**——最關鍵的響應處理

| 斷點 | 行為 |
|------|------|
| ≥ 1024px | 完整表格，所有欄位顯示 |
| 768〜1023px | 隱藏次要欄位，保留識別碼／名稱／狀態／數值 |
| < 768px | **表格轉為卡片列表**：每筆一張卡，識別碼與數值在第一行左右對齊，次要資訊在第二行，狀態膠囊在右下，整張卡可點 |

表格在手機上做水平捲動是下策——使用者看不到全貌、容易漏讀。卡片化雖然佔垂直空間，但每筆資料完整可讀。

**主體＋摘要面板**（左邊操作、右邊即時結果）

| 斷點 | 行為 |
|------|------|
| ≥ 860px | 左主體區 ＋ 右側 340px 摘要面板（並排） |
| < 860px | 單欄堆疊：主體在上、摘要在下 |
| < 768px | 摘要改為**底部固定條**：永遠停在畫面底部，顯示關鍵數值與主要動作按鈕；點一下展開完整明細 |

底部固定條是行動裝置的標準做法——使用者在上方操作時，關鍵數值與主要按鈕始終在拇指可及之處，不必捲到底。

**網格清單**

| 斷點 | 欄數 |
|------|------|
| ≥ 1024px | 4 欄 |
| 768〜1023px | 3 欄 |
| 480〜767px | 2 欄 |
| < 480px | 1 欄 |

**例外：商品卡列表在 480px 以下維持 2 欄。**商品卡列表指「圖片 ＋ 名稱 ＋ 價格」的格狀清單（電商的商品列表、目錄頁）。單欄時一屏只看得到一件商品，比價與瀏覽都很吃力，業界的電商在手機上幾乎都是兩欄。兩欄時卡片只剩 150px 左右寬，必須同時做到四件事：

1. 卡片內距收為 `--sp-3`（12px），欄間距收為 `--sp-3`。
2. 商品名稱最多兩行，超出以刪節號截斷（`-webkit-line-clamp:2`）。
3. 次要資訊只留最必要的：評價只留星等、拿掉評價數。
4. 「加入購物車」改為卡片右下角的圖示鈕（44 × 44px，`aria-label` 寫明商品名稱），不放文字按鈕。

其他網格清單（文章卡、服務方案、相簿）照上表在 480px 以下改單欄。完整示範見 `storefront_s*.html` 的「本週新品」。

**清單＋摘要**

| 斷點 | 行為 |
|------|------|
| ≥ 860px | 左清單 ＋ 右摘要（並排，摘要 sticky 吸附） |
| < 860px | 單欄：清單在上、摘要在下、主要動作按鈕滿版 |

### 6.4 行動裝置的通則

- **相鄰可點元件之間至少留 8px 間隔**（觸控目標尺寸見 5.4）。
- **表單欄位單欄化**，不在手機上並排兩個輸入框。
- **主要動作按鈕滿版寬度**（`width:100%`），次要動作放在其下方或收進「⋯」選單。
- **避免 hover 才出現的功能**。手機沒有 hover 狀態，所有功能必須用點擊可達。表格列的操作按鈕在桌機可以 hover 才浮現，但手機版必須常駐顯示。
- **輸入框加上正確的 inputmode**：數量與金額欄位設 `inputmode="numeric"`，電話設 `type="tel"`，這樣手機會直接跳出數字鍵盤。

### 6.5 欄格系統（v22）

**定義**：內容區鋪一張 12 欄流體格。欄數隨級別變（6.1：寬與特寬 12 欄、平板與中 8 欄、緊湊 4 欄），欄距固定，外邊距等於 6.2 的容器左右內距。欄寬由瀏覽器算，規範不給像素值。全站只有這一張欄格。

**混合格**：固定寬的區域不佔欄格——側欄 226px、主體旁的摘要面板 340px（6.3）、側滑面板 480／640px 都是固定寬；欄格只鋪在剩下的流體內容區。9.1 的側欄式框架就是這個做法。

**跨欄只開五種**：12（全寬）、6＋6（對半）、8＋4（主體加輔助）、4＋4＋4（三等分）、3×4（四等分）。其他分法不開放，避免每頁一種切法。寬級別以下的退化：

| 寬與特寬（12 欄） | 平板與中（8 欄） | 緊湊（4 欄） |
|---|---|---|
| 12 | 8 | 4 |
| 6＋6 | 4＋4 | 4、4 堆疊 |
| 8＋4 | 8 在上、8 在下 | 堆疊 |
| 4＋4＋4 | 4＋4，第三個換行 | 堆疊 |
| 3×4 | 4＋4、4＋4 | 堆疊（商品卡列表維持兩欄，6.3） |

6.3 的網格清單（4／3／2／1 欄）與商品卡兩欄例外維持不變：它們是一批同質卡片依寬度自動排列，不走跨欄。欄格管的是頁面上「不同區塊怎麼分寬度」，網格清單管的是「同一種卡片排幾欄」，兩者不衝突；網格清單整體放在欄格的一個 12 跨欄裡。

**欄距兩檔**（對標 Carbon 的欄距模式；只開兩檔，不開第三檔）：

| 檔 | 值 | 用在 |
|---|---|---|
| 標準 | `--sp-6` 24px | 預設，所有頁面 |
| 緊湊 | `--sp-3` 12px | 緊湊級別（< 480px，自動切換）；商品卡列表（6.3 的兩欄例外）；S6 石墨的資料密集儀表板、統計卡列與卡片格；密集模式（5.7）下全頁自動改用 |

緊湊檔只縮欄距，不改欄數、不改外邊距、不改卡片內距；卡片內距要跟著縮時依 6.3 商品卡的寫法另外指定 `--sp-3`。表格內部靠儲存格內距 12／20 處理，不需要第三檔。

**實作**：在 `dist/base.css`（結構層），風格檔不得覆寫。桌機與平板要用緊湊檔時加 `.dense`：

```css
.grid{display:grid;grid-template-columns:repeat(12,minmax(0,1fr));column-gap:var(--sp-6);row-gap:var(--sp-6)}
.col-3{grid-column:span 3}.col-4{grid-column:span 4}.col-6{grid-column:span 6}.col-8{grid-column:span 8}.col-12{grid-column:span 12}
.grid.dense{column-gap:var(--sp-3);row-gap:var(--sp-3)}
@media (max-width:1023px){
  .grid{grid-template-columns:repeat(8,minmax(0,1fr))}
  .col-3,.col-4{grid-column:span 4}.col-6,.col-8,.col-12{grid-column:span 8}
}
@media (max-width:479px){
  .grid{grid-template-columns:repeat(4,minmax(0,1fr));column-gap:var(--sp-3);row-gap:var(--sp-3)}
  .col-3,.col-4,.col-6,.col-8,.col-12{grid-column:span 4}
}
```

```html
<div class="grid">                      <!-- 統計卡列：3×4 -->
  <div class="statc col-3">…</div><div class="statc col-3">…</div>
  <div class="statc col-3">…</div><div class="statc col-3">…</div>
</div>
```

元件庫示範頁不畫欄格（欄格是頁面層的事），完整用法見 `dist/examples/s1-admin.html` 的統計卡列。**驗收**：不另設腳本——第二項檢查已掃間距是否在標尺上，第四項溢出檢查在 390 與 768 寬度確認欄格不會撐破版面。
