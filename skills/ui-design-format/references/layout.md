## 九、版型規範

### 9.1 後台：側欄式框架

```
┌──────────┬──────────────────────────────────────┐
│ 品牌區    │ 麵包屑              通知鈴  使用者資訊 │ ← 頂列 高 48px
│ Logo＋名  ├──────────────────────────────────────┤
│          │ 頁面標題                              │
│ 【分組一】│ 計數副標              說明 次要鈕 主鈕 │ ← 頁首區
│ 項目      │                                       │
│ 項目      │ ┌─統計卡─┬─統計卡─┬─統計卡─┬─統計卡─┐ │
│ 項目      │ └────────┴────────┴────────┴────────┘ │
│          │ ┌──────── 搜尋框 ─────────┐ 日期 ～ 日期│ ← 篩選區
│ 【分組二】│ ○全部 ○狀態A ○狀態B ○狀態C ○狀態D      │
│ 項目      │ ┌──────────────────────────────────┐  │
│ 項目      │ │ 表格（16px 圓角容器）              │  │
│          │ │  表頭帶                            │  │
│ 【分組三】│ │  資料列 …                          │  │
│ 項目      │ │  表尾：筆數                 P4 分頁 │  │
│ 項目      │ └──────────────────────────────────┘  │
│          │                                       │
│ 【系統】  │                                       │

│ 設定      │                                       │
│          │                                       │
│ 頁尾      │                                       │
└──────────┴──────────────────────────────────────┘
   226px                    最大 1060px
```

要點：

- 側欄依功能分組，組標題為 L2 微標籤樣式。
- 選中項為膠囊形，底色 `--acc-soft`、文字與圖示 `--acc`、字重 700。
- 頂列的麵包屑用文字呈現目前位置，不做可點層級以外的裝飾。
- 頁首區固定結構：左邊「大標題＋計數副標」、右邊「說明連結＋次要按鈕＋主按鈕」。
- 內容區鋪 12 欄格（6.5）：統計卡列為 3×4，篩選區與表格為 12。

### 9.2 前台：頂部分頁式

```
┌────────────────────────────────────────────────┐
│ 頁籤 │ 頁籤 │ 頁籤(2)          使用者狀態列      │ ← 頁籤列
├────────────────────────────────────────────────┤
│ 區塊標題 ─────────────────────────── EN LABEL  │
│ 搜尋框  ○全部 ○分類A ○分類B                      │
│ ┌ 提示框                                     ┐  │
│ ┌──卡片──┬──卡片──┬──卡片──┬──卡片──┐          │
└────────────────────────────────────────────────┘
```

要點：

- 頁籤採底線式（不是膠囊），與後台側欄的膠囊選中做出區隔，讓兩端一眼可辨。
- 右上角常駐顯示使用者目前的狀態資訊，讓使用者隨時確認自己看到的是哪一組內容。
- 區塊標題採「中文標題 ＋ 延伸細線 ＋ 英文小標」的組合。

### 9.3 頁面結構通則

任何新頁面都依此順序組裝，不要自創結構：

一、頁首區（標題＋副標＋動作按鈕）
二、摘要區（統計卡，選用）
三、篩選區（搜尋＋條件，選用）
四、主體區（表格／卡片／表單）
五、補充區（說明、相關資訊，選用）

區段之間間距 24px，區段內元素間距 12〜16px。

另外兩條結構規則（v21），針對「每個元件單看都對、放在一起卻線條打架」的情況：

六、**一處分隔只用一條線。** 區塊標題用了延伸細線（9.2 的「中文標題＋延伸細線」），下方就不再放分隔線或卡片標題列的底線；卡片標題列 `.card-title` 已有底線，標題就不再用延伸細線。兩個有框線的容器相鄰時也不再加分隔線——框線本身就是分隔。檢查方法：兩條線之間如果只有空白、沒有任何文字或元件，其中一條就是多餘的。

七、**有框線的元件相鄰時最小間距 `--sp-3`（12px）。** 按鈕列與輸出框、卡片與卡片、輸入框與按鈕，邊緣到邊緣至少 12px；並排的小按鈕、chip、膠囊可以用 `--sp-2`（8px，5.1 已允許）；低於 8px 視為框線貼合，第五項檢查不通過。刻意共用框線的組件不在此限：分段控制、數量調整器、分頁器、頁籤、表格內部，以及下拉選單與觸發元件之間的 `--sp-1`。

間距的三條原則（v22），讓看間距就能分出層級，不必靠框線或底色：

八、**內部間距 ≤ 外部間距。** 元件自己的內距不得大於它與鄰居的距離：卡片內距 16／20，卡片之間就至少 `--sp-6` 24px；儲存格內距 12／20，表格與下一個區塊之間至少 24px。內距比外距大，讀起來會黏成一團。

九、**區塊之間一律大於區塊內部。** 同一區塊裡的元素用 `--sp-3`〜`--sp-4`，區塊與區塊之間用 `--sp-6` 以上，頁面大區段用 `--sp-7`〜`--sp-8`。

十、**`--sp-1`、`--sp-2` 只用在元件內部，以及同一組並排的小元件之間。** 元件內部指圖示與文字、標籤到輸入框這類；同一組指一排並排的小按鈕、chip、膠囊（5.1 的 `--sp-2` 用途）。兩個獨立元件之間、或組與組之間最小 `--sp-3`——這就是第七條，兩條是同一條規則的兩面。這樣 4px 與 8px 不會跑到版面層。

對標：8pt 間距原則的「內部 ≤ 外部」與「相關的靠近、不相關的拉開」；本規範標尺以 4px 為基準，原則一樣適用。
