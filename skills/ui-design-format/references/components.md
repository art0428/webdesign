## 七、元件規範

本章定義**每個元件必須實作的狀態**——這是最容易被漏掉的部分。完整的視覺樣式與互動細節見各風格的元件庫檔案。

### 7.1 元件清單與必要狀態

| # | 元件 | 必須實作的狀態 |
|---|------|----------------|
| 1 | 按鈕 Button | 預設／hover／active 按下／disabled 停用／loading 處理中 |
| 2 | 輸入框 Input | 預設／focus 聚焦／error 錯誤／disabled／唯讀／有值與 placeholder |
| 3 | 下拉選單 Select | 收合／展開／已選／多選計數／搜尋中／無結果 |
| 4 | 選項標籤 Chip | 可選／已選／不可選（半透明劃線）／disabled |
| 5 | 數量調整器 Stepper | 預設／達下限（減號停用）／達上限／不符級距 |
| 6 | 核取與單選 | 未選／已選／disabled／群組必選提示 |
| 7 | 開關 Switch | 關／開／切換中／disabled |
| 8 | 狀態標籤 Badge | 五種語意色（見 3.7），一律「●＋文字」 |
| 9 | 表格 Table | 預設／hover 列／選取列／載入中（骨架屏）／無資料／載入失敗 |
| 10 | 卡片 Card | 預設／可點擊時的 hover／hero 強調版 |
| 11 | 分頁器 Pagination | 目前頁／可點頁／省略號／首末頁停用 |
| 12 | 彈窗 Modal | 開啟／關閉／確認型（雙按鈕）／危險型（紅色主按鈕＋二次確認） |
| 13 | 提示 Toast | 成功／錯誤／處理中；3 秒自動消失，可手動關閉 |
| 14 | 空狀態 Empty | 純空（首次使用）／篩選後無結果（兩者的差別見 7.3） |
| 15 | 載入 Loading | 骨架屏／轉圈圈（用哪一種見 7.3） |
| 16 | 警示條 Alert | 四個語意色各一種；可帶一顆文字動作鈕；成功與中性提示可關、錯誤與警告不可關（見 7.3） |
| 17 | 提示框 Notice | 單一中性樣式，不分語意色、不帶操作、不會消失（見 7.3） |

### 7.2 分頁器規格

全站統一使用 **P4 底線數字式**：無框純數字，目前頁為 accent-1 色＋字重 700＋2px 底線。放在表格外框的表尾區右側。選定理由是視覺重量最輕，不會跟表格內容搶注意力。

### 7.3 幾個容易做錯的元件

**數量調整器**：必須即時驗證數值範圍與級距規則。不符時不是跳錯誤訊息打斷使用者，而是「按鈕鎖住＋下方一行紅字說明」，讓使用者自己修正。

**空狀態**：兩種情境要分開處理。首次使用的空狀態要給行動指引（告訴使用者第一步可以做什麼）；篩選後無結果的空狀態要給「清除篩選」按鈕。用同一個畫面處理兩種情境是常見錯誤。

**載入中**：表格與列表一律用骨架屏。轉圈圈會讓使用者不知道要等多久、也不知道即將出現什麼；骨架屏先把版面撐開，內容到位時不會跳動。

**警示條與提示框**：這兩個元件最常被做得太重。警示條用**淡底 ＋ 1px 同色細框**，不再加粗左色條——底色、框線、左色條、圖示、獨立標題行五種手法同時用，四則排在一起整區就變成色塊牆。另外三條守則：

- **標題是選用的。** 一句話講得完就不要拆成標題加內文；標題與內文併在同一段，短訊息只有一行高。
- **動作最多一顆，而且是文字按鈕。** 實心膠囊鈕在淡底上太搶，會跟頁面的主按鈕打架。
- **錯誤與警告不給關閉鈕。** 使用者需要一直看到的訊息不該能被關掉；只有成功與中性提示可以關。
- **文字動作與關閉鈕要跟內文站在同一條基線上。** 它們現在是文字、不是按鈕，要和內文共用同一個行框（同字級、同行距、靠上對齊），不要再給它 `min-height`——按鈕那個 32px 的最小高度會把整列撐高，變成內文靠上、連結置中，差將近 6px。

提示框則改成**中性灰底塊**，不帶語意色也不帶品牌色、不加框線與左色條。提示框不代表「有事情要處理」，只是補充脈絡；長得像警示條就會被誤讀。

**危險動作**：所有不可回復的動作（刪除、取消、解除綁定）一律二次確認，且確認彈窗要寫明「會發生什麼」與「無法復原」，不是只問「確定嗎」。

### 7.4 圖示

**全站只用一套圖示：Lucide**（開源線條圖示庫，ISC 授權，可商用，只需保留授權聲明）。不得混用其他圖示庫，也不得混用線條與實心兩種畫法——同一畫面出現兩種畫法，會像兩個系統拼起來的。

| 尺寸 | 配哪一級字 | 用在哪 |
|---|---|---|
| 16px | B2、B3、L1 | 按鈕內的小圖示、表格列、標籤、說明文字旁 |
| 20px | B1、H3、主要按鈕 | 一般按鈕、表單欄位前後、側欄項目 |
| 24px | H2、獨立圖示鈕 | 頂列的搜尋、會員、購物車、選單；服務承諾列 |
| 48px | — | 空狀態、結果頁、圖片佔位的插圖 |

- **線寬一律 2**（Lucide 預設），四個尺寸都不改。不得用縮放圖示來湊出中間尺寸。
- **顏色跟著文字走**（`stroke="currentColor"`），預設是文字色或次要文字色；只有在「它本身就是操作」時用主色。語意色只給狀態圖示（錯誤、警告、成功、資訊）。
- **圖示與文字的間距**：16px 圖示配 `--sp-1`（4px），20px 以上配 `--sp-2`（8px）；圖示與文字垂直置中對齊。
- **純圖示按鈕必須有 `aria-label`**（給螢幕報讀器念的名稱），可點擊範圍至少 44 × 44px（見 5.4）；不是所有人都看得懂圖示，常用的才可以不帶文字（搜尋、關閉、選單、購物車），其餘一律圖示加文字。
- **裝飾性圖示加 `aria-hidden="true"`**，旁邊已經有文字的圖示屬於裝飾，不要讓報讀器重複念。
- **版本要鎖定**：專案引用的 Lucide 版本寫死（例如 1.52.0），不要用 `latest`，否則圖示形狀會在某天無聲改變。
- **風格不改圖示**：七套風格共用同一組圖示，手帳風格也不換成手繪圖示。圖示是語意，不是材質。
