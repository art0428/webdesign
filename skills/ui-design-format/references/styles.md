## 八、風格家族 S1〜S6

### 8.1 風格與結構的關係

風格是「殼」，結構是「骨」。第三章到第七章的所有規範（色彩三層、字級層級、間距標尺、元件狀態、RWD 行為）**六套風格一體適用**。風格只改變表面材質——陰影、背景、框線質感、形狀細節。

因此換風格不需要重寫元件邏輯，只需要替換一組樣式定義。

### 8.2 六套風格定義

| 編號 | 名稱 | 英文代號 | 材質原理 | 個性 | 建議用途 |
|------|------|----------|----------|------|----------|
| S1 | 奶油 | CREAM | 暖白底、大圓角容器、1px 暖灰線、零陰影 | 最穩、最中性 | **系統預設**；後台標準；資料密集畫面 |
| S2 | 浮雕 | EMBOSS | 元件與背景同色，靠一明一暗柔和陰影做出微凸微凹 | 觸感最強 | 操作元件多、資料密度低的畫面 |
| S3 | 琉璃 | GLAZE | 品牌雙色漸層當背景，半透明毛玻璃面板浮於其上 | 品牌感與科技感最強 | 前台首頁、登入頁、行銷頁 |
| S4 | 手帳 | DOODLE | 暖紙質底、手繪不規則外框、硬影位移、紙膠帶與螢光筆 | 最有人味 | 餐飲、文創、年輕客群的前台 |
| S5 | 極光 | AURORA | 品牌雙色柔霧暈染背景、一角收尖的有機圓角 | 溫和現代 | 品牌故事頁、服務型前台 |
| S6 | 石墨 | GRAPHITE | 純無彩色近白底、1px 細線、零陰影、小圓角、技術識別碼用等寬字 | 冷靜、精準、低裝飾 | 後台、資料密集儀表板、開發者與內部工具、設定頁 |

**S2 的互動語意**：凸＝可以按、凹＝已選中或輸入區。這組隱喻要貫徹全站，不可混用。

**S5 的漸層紀律**：漸層只准出現在三個地方——強調按鈕、重點標記、hero 數字與目前狀態節點。其餘一律純色。漸層一旦濫用立刻顯得廉價。

**S6 的三條鐵則**：一、側欄與頁面同色，只有卡片是白的——「只有資料躺在白紙上，其餘都是同一張桌面」；做成側欄白、頁面灰就變成另一套風格。二、灰階是純無彩色，不得帶色偏（見 3.5）。三、表格區不用品牌色，只有選取列例外——篩選膠囊選中、側欄 hover、分段控制都用中性灰 `--sel`，品牌色只留給主按鈕、連結、側欄選中項、目前頁籤、選取列。這三條是 S6 安靜的來源。

**S1 與 S6 是一對**：奶油是暖的、軟的，給文件與對外畫面；石墨是冷的、硬的，給工程師與內部工具。後台預設仍是 S1；當專案希望後台有「工具感」而不是「文件感」時選 S6。

### 8.4 矩陣判定的理由與調整方式

**S1 奶油：全部可用。**這是它作為預設風格的價值——中性到不挑色。暖白底與暖色系（C6、C7、C8、C11、C12）最和諧；C4 電光紫彩度最高，在奶油的克制氣質裡略跳，列為可用。

**S2 浮雕：偏好中明度、與底色同調的顏色。**浮雕的底色是冷灰藍 `#E6EAF0`，靠柔和陰影營造立體。

- △ C6 胡桃棕、C7 焦糖磚橘、C8 暖墨：暖色與近黑放在冷灰底上會顯得髒或太硬。**調整方式**：把底色整組換成暖灰 `#EDE8E0`，陰影色同步調暖。
- ✕ SC1：亮黃塊在冷灰底上像貼紙，且副色與底色邊界對比只有 1.35，選型介面直接鎖住。

**S3 琉璃：需要兩個色有足夠色相差才能形成漂亮漸層。**十二組都沒有純黑，不再需要漸層專用替代色。

- ○ C6、C7、C8、C11、C12：兩端彩度低或一端接近墨色，漸層乾淨但平淡，適合想低調的專案。
- ◎ SC1：深綠到相思黃的漸層疊白玻璃後是淡奶黃，是琉璃最好看的組合之一。

**S4 手帳：需要暖色或高彩度，冷靜的顏色與手繪氣質互斥。**

- ◎ C5〜C9、C11、C12：暖色與自然色在暖紙底上最自然。
- △ C3 深靛、C4 電光紫：偏冷，彩度高勉強可用；若必須使用建議改選 S1。
- △ SC1：暖紙底偏黃，黃色塊會糊進去；副色填色元件自動加 1px 墨色框線後可用（語彙即「螢光筆」）。

**S5 極光：需要能柔和暈開的中低彩度色。**

- △ C7 焦糖磚橘、C8 暖墨：一端是近黑的暖墨，暈染開來偏灰，不是發光。若要用，把暈染改成只取主色端。
- ◎ SC1：深綠與黃的柔霧暈染即極光本身，是 SC1 最推薦的風格。

**S6 石墨：六套裡對色系最寬容的一套**，沒有任何一格「需調整」或「鎖住」。原因是這套風格本來就把品牌色壓到最少——主色只出現在主按鈕、連結、選中列、目前頁籤、側欄選中項；副色只出現在來源標記、圖表第二數列、趨勢數字三處，剛好是 3.4「副色每頁最多三處」的上限。深色系（C8 暖墨）與亮色系（C4 電光紫、C10 節慶桃紅）都不會失控。

- ○ C6 胡桃棕、C7 焦糖磚橘、C11 燒橄欖、C12 玫瑰棕：暖色系放在純無彩色的冷灰結構上略有色溫衝突，但對比全數通過，可用。若專案以暖色為品牌主色，建議優先考慮 S1 奶油。
- ◎ SC1：白卡上的黃色塊乾淨，判定同 S1。

### 8.5 通則：近黑色系用在漸層類風格

十二組核心已無純黑（原含純黑的四組於 v5 退場或改為暖墨、炭灰），v4 的「純黑替代色」與 `--acc-grad` 第四組變數**整段刪除**。剩下的一條通則是：C7 焦糖磚橘的副色炭灰 `#2B2B2B` 與 C8 暖墨的主色 `#23201E` 屬近黑，在 S3 琉璃可用（玻璃會提亮）、在 S5 極光列為需調整（暈染只取另一端的彩色）。

### 8.6 風格的技術實作

每套風格是一個獨立的 CSS 檔案（或一個 class 命名空間），載入後覆寫元件的表面樣式，**不碰任何色彩變數與尺寸變數**。

```html
<!-- 風格以 class 掛在根元素，色系以 CSS 變數注入 -->
<body class="style-cream"
      style="--acc:#B4552D;--acc-soft:#F8EBE3;--acc-deep:#A54C27;
             --acc2:#212121;--acc2-soft:#ECECEC;">
```

```css
/* base.css：所有風格共用的結構、字級、間距、RWD */
/* style-cream.css：.style-cream .card{ border:1px solid var(--line); border-radius:16px; box-shadow:none } */
/* style-emboss.css：.style-emboss .card{ border:none; box-shadow:7px 7px 14px var(--sh-d), -7px -7px 14px var(--sh-l) } */
/* style-graphite.css：.style-graphite{ --page:#FBFBFB; --card:#FFF; --line:#E3E3E3; --r-lg:12px; --r-sm:6px } */
```
